# Git commit messages

When creating Git commits:
- Never add Co-authored-by trailers.
- Never mention AI, agents, assistants, Claude, ChatGPT, Codex, Cursor, Copilot, or similar tools in commit messages.
- Never add Generated-by, Assisted-by, Signed-off-by, or attribution trailers related to AI tools.
- Commit messages must contain only the human-authored commit message.
